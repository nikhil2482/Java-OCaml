# CIS 1200

Projects from a programming course in OCaml and Java, Spring 2023. This repository is private.

## OCaml

1. **DNA.** Analyzes DNA sequences with recursive list functions, with tests.
2. **Sets and trees.** Binary search trees, higher order functions, and two set implementations behind one interface, used to build a vocabulary tool.
3. **Queues.** Mutable linked queues and a deque, plus graph code built on them, with tests.
4. **Paint.** A paint program built on a small GUI widget library written from scratch.

## Java

5. **Image processing.** Pixel and image manipulations such as color transforms and filters, with tests.
6. **Chat server.** The server model for a chat app with users, channels, and permissions, with tests.
7. **Twitter bot.** Parses tweets from a file and generates new ones with a Markov chain, with tests.
8. **Snake.** A Swing game with a growing snake and different foods, with tests.

Each folder holds the source code for that project.
